# AtCoder 学習用リポジトリ

AtCoderの解答コードおよびC++の学習記録を残すリポジトリです。

## 開発ルール

### ブランチ命名規則
- コンテスト・問題解答: `feature/<contest-name>` (例: `feature/abc350`)
- 環境構築・設定変更: `chore/<description>` (例: `chore/cpp-setup`)

### コミットメッセージプレフィックス
- `solution:` 解答コードの追加・編集
- `update:` コードの改善・コメントの追加
- `docs:` READMEや解説メモの更新
- `chore:` 設定ファイルの変更
