# ファイル・フォルダ記載ルール

フォルダおよびファイルの作成ルールを記載したドキュメント

## 作成ルール

- 適宜README.mdを配置して、フォルダの説明をすること
- フォルダ名はAtCoderContest以外は、小文字のkebab-caseを使うこと

## フォルダの種類

- ABC: atcoder beginer contest の解答を残すフォルダ
    - フォルダ名: コンテストの回数
    - 回答コード: a.cpp, b.cpp, ...
    - 学習メモ: learning.md
- tessoku: 競技プログラミングの鉄則の解答を残すフォルダ
    - フォルダ名: 章名
    - 解答コード: テキストの問題番号.cpp
